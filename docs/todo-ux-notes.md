## 2. 和讨论稿不一样的地方（有意的偏离）

1. **多选入口是顶栏按钮，不是「长按圆圈」**：圆圈本身是可点的勾选框，长按它会和「长按拖动」冲突。以后若要改，需要让圆圈和行用不同的手势区域。
2. **同一分区内的手动排序没做**：分区内按「截止 → 优先级 → sortOrder」排。拖动只用来「跨区改期 / 变子任务」。`sortOrder` 字段还在，要做的话在 `TodoScreen.kt` 拖动逻辑里加「同区落点 → 重写 sortOrder」。
3. **滑动手势不可自定义**：右滑 = 完成，左滑 = 改期。讨论稿里的「可配置」没做。
4. **小组件不用 Glance**：全部是 RemoteViews，少一个依赖，也避开 Glance 与 AGPL 依赖审查的麻烦。代价是样式简单、课表组件最多显示 6 节。
5. **新增待办默认进「收集箱」**（无日期）。只有点分区的「＋」才会带日期：今天 = `startDate=今天`（不会次日变红），其它分区 = 当天 23:59 截止；收集箱不设日期。
6. **课表小组件表头用「学期名 · 日期 周几」**：数据里没有「学校名」字段。想要学校名，需要在学期里加一个字段再改 `ScheduleWidgetProvider.build`。
7. **逾期整理卡只在逾期 ≥ 2 条时出现**；只有一条时直接在列表里处理。
8. **「下一件事」卡没课时回退为逾期 / 今天里最靠前的一条**，它会和下面的列表重复出现一次，这是有意的（置顶提醒）。
9. **「不做了」的任务在 Web 端显示成已放弃**（Web 已渲染 `dropped`；服务端仍存不透明 JSON）。

## 3. 真机必测清单（按风险从高到低）

### 手势（最容易出手感问题）
- **长按拖动**：长按一行 → 出现浮层标题 → 拖到另一分区标题或其行上松手。
  - 拖到屏幕上 / 下边缘应自动滚动。调参：`TodoScreen.kt` 里 `96.dp`（上边缘区）、`220.dp`（下边缘区，要避开底栏）、`28f`（最大滚动速度）。
  - 拖动期间列表 `userScrollEnabled=false`、行的左右滑动被关掉。如果在某些机型上长按后仍然触发滚动或滑动，说明系统手势冲突，需要把拖动改成 `Initial` 阶段拦截。
  - 小米 / MIUI：边缘返回手势可能吃掉靠边的右拖，重点测「拖到行右半区变子任务」。
  - 命中判断用 `listState.layoutInfo.visibleItemsInfo` 的 `offset`；如果拖到某一行时命中偏上 / 偏下几个 dp，是 `contentPadding.top = 8.dp` 没被扣除，在 `hitKey` 里减掉即可。
  - 长按后不动直接松手，会被当成一次点击（可能误开抽屉或误勾选）。若碍事，在 `TodoRow.onClick` 里已经用 `drag.active` 兜了抽屉，勾选圆圈没兜。
- **左滑改期**：左滑应弹出「改期」抽屉，行自动回弹；右滑勾选。若 MIUI 全面屏手势把左滑吃成返回，需要在行内留出左右边距（目前整行可滑）。
- **多选**：顶栏「☑」进入；底部操作条会盖住快速添加；批量操作后自动退出多选。

### 小组件 / 入口
- 待办小组件：勾选、点行、刷新延迟（RemoteViews，不是实时的）。
- 课表小组件：当前课高亮是靠「课程开始 / 结束时刻」的不精确闹钟刷新（`AlarmManager.set`），**省电策略严格的机型可能晚几分钟**；数据变更时会立即刷新。空状态文案为「(〃'▽'〃) 今天没有课啦」。
- 快速设置磁贴、桌面长按快捷方式、通知上的「完成 / 1 小时后再提醒」按钮、分享到薄荷日程、划词「添加到薄荷日程」。
- 多行分享（比如从备忘录分享一个清单）应跳到待办页并弹出批量预览。

### 提醒
- 设置 → 更多 → 提醒可靠性自检：逐项绿勾；点「1 分钟后发测试提醒」后**立刻锁屏并划掉应用**，看是否准时弹出。小米需要同时打开「自启动」并把省电策略设为「无限制」，页面里已写了步骤，但这些系统开关**没有公开 API 可检测**，只能靠这条测试验证。
- 上课前提醒：为某门课建一条「下节课前」的待办，提前提醒应带上「课前要交：xxx」。
- 每日摘要：开启后第二天 7:30 应收到通知；没有任何安排的日子不会发。

### 其它
- 教务同步（之前做的）：CAS 登录、周日晚的自动同步闹钟。
- 抽屉自动保存：改字段 → 下滑关闭 → 应该只产生一条可撤销记录。
- 暗色模式下各卡片对比度：「下一件事」卡（primaryContainer）、「空档推荐」卡（secondaryContainer）、分区高亮色。
- 语音输入：需要设备带系统语音识别（`RecognizerIntent`）；没有时只弹一个提示，不会崩溃。
- 剪贴板：Android 12+ 读取剪贴板会弹系统的「已粘贴」提示，属正常。

## 5. 已知风险 / 限制

- **待办页是整体重写的**，旧的「今日 / 计划 / 全部 / 已完成」筛选胶囊没有了（被时间线分区取代）。老用户需要适应；`SmartList` 仍在核心层，别处（小组件、Agenda）还在用。
- 拖动、自动滚动、搜索、多选等状态存在 `rememberSaveable` / `remember` 里，横竖屏旋转后拖动会被取消，其它会保留。
- 批量完成对重复任务会各自生成下一次实例（与单个完成一致），一次撤销全部回退。
- 「不做了」不会触发重复任务的下一次实例。
- 子任务只支持一层；拖拽设为子任务时，被拖的任务自己有子任务会被拒绝（无提示）。
- 搜索只看顶层任务的标题 / 备注 / 标签 / 清单名，子任务命中时父任务显示。
- 课程名里带空格时，`/课名` 语法按「去掉空格后」匹配；重名课程取第一个。
- 提醒调度最多排 40 条（`ReminderScheduler.MAX`），摘要通知占用其中的名额。

- 分享图片 → 变成待办附件
- 桌面图标角标
- 自动备份
- Web 端跟进（时间线分区、多选等；`dropped` 已渲染）
- 课表小组件的「周视图 / 点课进详情」
- 空档推荐的「下一个空档」「换一个」

## 7. 2026-10-25 真机细节精修

方向：看得清今天、顺手安排下一件事。沿用 Material 3 与现有配色；根 Tab 内容仍直接切换，不增加整页缩放和回弹。

- 待办标题最多两行，日期移到标题下方，不再挤占标题宽度；分区折叠和子任务展开入口至少 48dp，并提供展开状态。
- 「下一件事」把课程名与日期、时间、教室分开排；课程区域可直接打开课程编辑页。
- 快速添加只保留一层容器，输入后显示 Material 3 色调添加按钮。列表按添加区 / 批量操作区的实测高度让位，130% 字体下日期和添加目标标签不再叠住；拖动滚动边界跟随实际列表视口。搜索时收起快速添加，搜索按钮变为关闭；系统返回先关闭搜索或多选，再离开待办。
