# S011 Web 端（网页版客户端）

## 背景与目标
同步服务端已经能存数据，用户希望在电脑 / 手机浏览器里也能直接看课表、管日程和待办。Web 端是同步服务的**另一个客户端**，与 App 读写同一份记录（同一套 JSON 格式），**手机与 PC 都要可用**。

## 非目标
- 不做离线安装之外的后台推送提醒（浏览器没有可靠的定时提醒）。
- 不含：ICS / xlsx 导入、AI 与脚本的「高级修改」、快递短信识别、分享链接 / 订阅、教务系统导入、英文翻译。
- 重复日程只支持整体修改（不支持「仅此一次」例外）；操作历史（撤销栈）不同步，Web 端只对「删除」提供短时撤销。

## 行为
- **入口**：`http://服务器:8080/`（Go 服务端内嵌，随二进制发布，无需另起服务）；`/admin/` 仍是管理后台。
- **登录**：用户名 + 密码（与 App 相同账号，无开放注册）。勾选「保持登录」令牌存 `localStorage`，否则存 `sessionStorage`；退出登录会注销该设备令牌并清除本地缓存。
- **页面**（hash 路由）：今日 `#/today`、课表 `#/timetable`、日历 `#/calendar`、待办 `#/todo`、设置 `#/settings`。
  - 今日：当天课程 / 日程 / 待办时间块的时间线 + 今日待办 + 进度；PC 为两栏。
  - 课表：周视图（节次时间列、今天高亮、周切换 / 跳到本周），点击课程看详情，可编辑、删除、对某一周调课或停课。
  - 日历：月视图（课程 / 日程 / 待办圆点、周次列）+ 选中日的议程；PC 议程在右侧。
  - 待办：智能清单（今天 / 未来 7 天 / 全部 / 已逾期 / 已完成）+ 自建清单；快速添加；子任务、优先级、截止（可含时间）、重复（完成后生成下一次）。
  - 设置：学期管理（周次、节次时间）、主题（预设色 + 自定义种子色，跟随系统深浅色）、改密码、导出 JSON、退出登录；管理员有 `/admin/` 入口。
- **响应式**：< 700px 为手机布局（底部导航、表单用底部抽屉）；≥ 900px 为 PC 布局（左侧导航、宽屏双栏、居中弹窗）。深色模式跟随系统。
- **同步**：与 App 相同的规则（先拉后推、`updatedAt` 大者胜、墓碑、游标分页）。本地改动先写内存与 `localStorage` 缓存，再异步推送；断网时保留待推送队列并定时重试；切回页面 / 网络恢复 / 每 30 秒自动同步一次。
- **PWA**：提供 `manifest.webmanifest` 与图标，可「添加到主屏幕」。没有 Service Worker（数据缓存在 `localStorage`，不做离线打开页面）。
- **兼容**：Web 端创建的记录字段、枚举（`MANUAL`、`WEEKLY` 等）、时间格式（`YYYY-MM-DDTHH:mm`）与 Kotlin `:core` 完全一致；未识别的字段原样保留回写。
- **安全**：脚本与样式只允许同源（CSP `script-src 'self'; style-src 'self'`，无内联脚本 / 样式）；渲染一律用 `textContent` / DOM API，不拼 HTML。令牌存浏览器存储意味着同源 XSS 会泄露它，因此保持零第三方脚本；公网部署必须用 HTTPS。

## 技术取舍
见 [ADR-0006](../adr/0006-web-client-vanilla-esm.md)：原生 ES 模块、无构建、`go:embed`。

## 验收
- 手机（窄屏）与 PC（宽屏）都能完成：登录 → 看今日 / 课表 / 日历 → 新增课程、日程、待办 → 勾选完成 → 删除并撤销 → 修改学期 / 主题 / 密码 → 退出。
- 在 Web 端新增的记录，手机 App 同步后可见且字段正确；App 端的改动在 Web 端同步后可见。
- 断网时修改不丢，恢复后自动推送；刷新页面后待推送的修改仍在。

## 测试
- `webtest/model.test.mjs`：日期工具、周次、课程展开（调课 / 停课）、事件重复与跨天、待办筛选与完成、重复待办、同步元数据（11 项）。
- `webtest/sync.test.mjs`：两台设备同步 / 冲突 / 离线缓存与恢复 / 1200 条分页 / 改密码（6 项）。默认对内置模拟服务运行；`scripts/web-e2e.sh` 启动真实 Go 服务端再跑一遍。
- `server`：`TestWebAppServed`（入口页、JS / CSS / manifest / 图标、CSP、缓存头、404）。
- `:core`：`WebCompatTest` 解码 `core/src/test/resources/web-records.json`（由 Web 端工厂经 `server/webtest/gen-fixture.mjs` 生成）。
- 人工：用 Chromium 截图（`webtest/shots.mjs`，手机 / 桌面 × 浅色 / 深色）检查布局；**未在真实手机浏览器、Safari、Firefox 上验证**。
