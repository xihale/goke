# S015 云端 MCP：自建同步服务接口

## 背景与目标

App 不内置 AI。自建同步服务提供标准 MCP（Model Context Protocol）端点，任何远程 MCP 客户端（Claude、Claude Code 等）使用账号令牌连接后，即可读写用户的云端同步数据；写入走与客户端 `push` 完全相同的 LWW 记录同步路径，各端自然收敛。

若需在本机或局域网直接操作 App 本地数据并调用 QuickJS「高级修改」脚本，请使用 App 内置的 **本地 MCP 服务**（见 [S016](016-local-mcp.md)）。

## 非目标

- OAuth 授权（沿用 Bearer 用户令牌，详见 [server/README.md](../../server/README.md)）。
- 服务端展开重复课程/节次时间（`get_agenda` 按已落库记录筛选）。
- 旧版 `Event` 写操作（日程已并入 `Task`，仅保留只读兼容查询 `search_events`）。

## 行为

- **端点与传输**：`POST /mcp`，Streamable HTTP（无状态 JSON 响应），使用 `github.com/modelcontextprotocol/go-sdk`；鉴权同同步接口（`Authorization: Bearer <token>`，缺失或无效返回 401）。
- **工具集与启动预热**：按 `(store, userID)` 缓存，服务启动调用 `Warmup()` 校验 Schema；业务错误返回 `IsError` 工具结果。
- **工具（11 个）**：
  - 清单：`list_lists`、`create_list`
  - 待办/日程：`get_task`、`search_tasks`、`create_task`、`update_task`、`complete_task`、`delete_task`
  - 日程/课表：`get_agenda`、`search_events`（只读）、`list_courses`
- **写入与并发语义**：
  - 服务端生成记录 UUID、`updatedAt = now`、`source = CODE`，JSON 显式写出全量默认值与 `_t` 判别字段；删除写双端墓碑并级联删除存活子任务，重复删除幂等。
  - 改/完成/删除采用「读 → 变换 → 推」，若被设备新版本抢先写（LWW 拒绝），自动重读重试至多 3 次。
  - 不变式与 App 一致：子任务仅一层、新增按层追加 `sortOrder`、`dueHasTime=true` 须带截止日期、`blockMinutes` 与 `blockStart` 成对；字符串传空串清除、`remindMinutes ≤ 0` 清除、`freq=NONE` 清除重复。
  - 设备端登录态下通过 WorkManager（15 分钟周期）及打开 App 自动拉取到达本机。
- **隔离与防漂移**：所有查询强制过滤 `userID`；`internal/mcp/mcp_test.go` 使用 `:core` 生成的 `web-records.json` 夹具回放全部读取视图，防止模型结构漂移。

## 验收与测试

- `server`：`internal/server/mcp_test.go`（鉴权、wire 格式、LWW 重试、级联/幂等、隔离）、`internal/mcp/mcp_test.go`（夹具回放），`go test ./...`。
- E2E：`server/webtest/mcp.test.mjs` 验证真实服务端上云端 MCP ↔ Web 客户端双向收敛（`bash scripts/web-e2e.sh`）。
