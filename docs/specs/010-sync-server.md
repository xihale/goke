# S010 自建同步服务与「账号与同步」

## 背景与目标
App 本地优先。想在多台设备间同步的用户可以自建服务器：管理员创建账号，用户登录后数据按记录同步。**不登录 = 本地模式，行为与以前完全一致。**

## 非目标
开放注册、邮箱验证与找回密码、第三方登录、端到端加密、多人协作、操作历史同步、后台定时同步（目前在打开 App、数据变化后同步，或手动同步）。

## 行为
- **服务端**（`server/`，Go + SQLite）：用户名 + 密码登录，每台设备一个令牌；管理员后台 `/admin/`；`pull` / `push` 同步接口。详见 ADR-0005、`server/openapi.yaml`、`server/README.md`。
- **冲突**：单条记录 `updatedAt` 较大者胜；相同内容空操作；被拒绝的推送返回服务器版本，客户端覆盖本地。删除用墓碑（`deletedAt`）同步。
- **客户端同步顺序**：先拉取（游标）再推送（本地水位线之后改动的记录 + 待告知的墓碑）。
- **首次登录**：服务器已有数据而本地只有自动创建的默认学期时，丢弃本地默认学期，避免出现两个学期。
- **撤销「新增」**会物理删除记录：登录状态下留下墓碑，下次同步告诉服务器，拉取时不会把它带回来。
- **退出登录**：回到本地模式，本地数据保留，服务器数据不动。
- UI：设置 →「账号与同步」。未登录显示服务器地址 / 用户名 / 密码；`http://` 地址给出风险提示；已登录显示上次同步时间、立即同步、修改密码、（管理员）打开管理后台、退出登录。
- 令牌用 Android Keystore 加密保存，不进备份（`secrets.xml`、`sync.xml` 已从备份中排除）。

## 验收
- 给定管理员创建了用户 alice，当 alice 在设备 A 登录并推送，设备 B（全新）登录，则 B 得到 A 的学期与课程且只有一个学期。
- 一台设备改名 / 删除 / 新增后撤销，另一台同步后一致。
- 普通用户不能访问管理接口；不能停用、降级、删除最后一个可用管理员；重置密码或停用后该用户所有设备令牌失效；登录失败过多被限速。
- 推送校验：空 id、非对象 data、非法 updatedAt 被拒绝；用户之间数据隔离。
