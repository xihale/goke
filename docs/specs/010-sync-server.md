# S010 自建同步服务与「账号与同步」

## 背景与目标

App 本地优先。需要在多台设备间同步或配合 Web / 云端 MCP 使用的用户，可部署自建同步服务：管理员创建账号，用户登录后按记录双向同步。**不登录 = 纯本地模式，行为与未启用同步时完全一致。**

## 非目标

开放注册、邮箱验证与找回密码、第三方登录、端到端加密、多人协作、操作历史（撤销栈）同步。

## 行为

- **服务端**（`server/`，Go + SQLite）：用户名 + 密码登录，每台设备一个令牌；管理员后台 `/admin/`；`pull` / `push` 同步接口。详见 [ADR-0005](../adr/0005-go-self-hosted-server.md)、[openapi.yaml](../../server/openapi.yaml)、[server/README.md](../../server/README.md)。
- **冲突**：单条记录 `updatedAt` 较大者胜（LWW）；相同内容空操作；被拒绝的推送返回服务器版本覆盖本地。删除用墓碑（`deletedAt`）同步。
- **客户端同步顺序**：先 `pull`（游标）再 `push`（本地水位线之后改动的记录 + 待告知墓碑）。
- **同步触发**：打开 App、本地数据改动、登录/手动点击「立即同步」，以及登录状态下的 **15 分钟后台周期同步**（`PeriodicSync`，WorkManager，联网时触发），确保外部（Web / 云端 MCP / 其他设备）写入自动到达本机。
- **首次登录**：服务器已有数据而本地仅剩自动创建的默认学期时，丢弃本地默认学期，避免出现重复学期。
- **撤销「新增」**会物理删除记录：登录状态下保留墓碑供下次同步通知服务器，拉取时不会复活。
- **退出登录**：回到本地模式，保留本地数据，服务器数据不动。
- **UI & 凭据**：设置 →「账号与同步」，`http://` 地址提示明文传输风险；令牌经 Android Keystore 加密存于 `SecretStore`，已从系统备份排除。

## 验收

- 管理员创建用户后，设备 A 登录推送，全新设备 B 登录后得到一致的学期、课程与待办且不重复创建默认学期。
- 一端改名 / 删除 / 新增后撤销，另一端同步后一致。
- 权限与校验：普通用户无法访问管理接口；无法停用/降级/删除最后一个可用管理员；重置密码或停用后该用户所有设备令牌失效；登录失败限速；推送非法 payload 被拒；用户间数据隔离。

## 测试

- `server`：`go test ./...`（认证、限速、管理员保护、同步 LWW/墓碑/分页/隔离/校验、后台页与 CSP）。
- `:core`：`SyncTest`（编码往返、墓碑、未知类型跳过、待推送、合并、首次登录判定）。
- `:app`：`SyncIntegrationTest`（`bash scripts/sync-e2e.sh` 驱动两台模拟设备对真实服务端同步）；`ScreensSmokeTest` 渲染同步页。
