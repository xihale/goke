# S009 提醒、小组件与快递识别

## 背景与目标
课程/事件提醒（精确闹钟，开机恢复）、桌面小组件、通知使用权监听识别取件码并生成待办；AI 生成代码（用户自备 OpenAI 兼容 Key）。取件待办自动排进可设置的取件时段（默认 14:00–22:00，快递下午/晚上下班后再拿；过结束时刻排明天），驿站截止仍作 due 并提醒。

## 验收

## 测试
